# Mi Primer Proyecto Android

Este es el proyecto final completo para la tarea calificable de Android.

## Características Implementadas

1. Multilenguaje: Español (default), Inglés (en), Francés (fr), Alemán (de).
2. Nine-Patch (fondo.9.png): Estiramiento en cielo azul, marcianito protegido.
3. UI Adaptativa: ConstraintLayout responsivo.
